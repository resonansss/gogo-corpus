# Библии на гого и суахили

Основные тексты находятся в [bible_com/](bible_com/README.md). Они извлечены
из сохранённых страниц двух изданий Bible.com:

- **Гого:** [Luganuzi Luswanu Kuli Wanhu Wose 2002](https://www.bible.com/versions/3039-llkww-luganuzi-luswanu-kuli-wanhu-wose-2002), LLKWW, ID 3039.
- **Суахили:** [Biblia Habari Njema](https://www.bible.com/versions/74-bhn-biblia-habari-njema), BHN, ID 74.

Для каждого языка сохранены 39 книг и 929 глав Ветхого Завета,
27 книг и 260 глав Нового Завета — всего 66 книг и 1189 глав.
Отдельные страницы введений `Intro` и всплывающие сноски не включены.

## Где лежат тексты

- `bible_com/gogo/` и `bible_com/swahili/` — папки по языкам.
- В каждой папке книги: `001.txt`, `002.txt` и далее — главы, `book.txt` — вся книга.
- Папки книг названы `01_OT_…` — `39_OT_…` и `40_NT_…` — `66_NT_…`, где `OT` — Old Testament (Ветхий Завет), `NT` — New Testament (Новый Завет).
- В папке языка `bible.txt` содержит все 66 книг, отдельно представлены `ot_bible.txt` — Ветхий Завет,
  `nt_bible.txt` — Новый Завет. Файл `contents.txt` содержит оглавление с числом глав.
- [manifest.json](bible_com/manifest.json) связывает главы с адресами Bible.com,
  исходными HTML-страницами и контрольными суммами TXT.

Тексты записаны в UTF-8. Сохранены номера стихов, заголовки и порядок чтения
на сайте. Элементы интерфейса и всплывающие сноски исключены, пробелы
нормализованы.

## Повторный экспорт

Для запуска из корня проекта:

```powershell
python export_bible_com_texts.py --download
```

Скрипт скачает недостающие страницы и соберёт TXT. Для повторной сборки из уже
сохранённых HTML: та же команду без `--download`. 
Подробности об отличиях
между новой загрузкой и пересборкой — в [описании выгрузки](bible_com/README.md).
