# Библии на гого и суахили с Bible.com

Здесь находятся тексты непосредственно со страниц Bible.com:

- [gogo](gogo/) — **Luganuzi Luswanu Kuli Wanhu Wose 2002**, LLKWW, версия 3039;
- [swahili](swahili/) — **Biblia Habari Njema**, BHN, версия 74.

В каждом языке — 66 книг и 1189 глав: 39 книг и 929 глав Ветхого Завета,
27 книг и 260 глав Нового Завета. Это все книги и нумерованные главы,
перечисленные в разделах Old Testament и New Testament на страницах этих версий.
Отдельные страницы введений `Intro` в выгрузку не включены.

## Как устроены файлы

```text
bible_com/
  gogo/
    01_OT_Mwamulizo/
      001.txt
      002.txt
      ...
      book.txt
    02_OT_Wutuluce/
      ...
    40_NT_Matayo/
      ...
    contents.txt
    bible.txt
    ot_bible.txt
    nt_bible.txt
  swahili/
    01_OT_Mwanzo/
      001.txt
      002.txt
      ...
      book.txt
    02_OT_Kutoka/
      ...
    40_NT_Mathayo/
      ...
    contents.txt
    bible.txt
    ot_bible.txt
    nt_bible.txt
```

- `001.txt`, `002.txt` и далее — отдельные главы.
- `book.txt` — все главы данной книги подряд.
- `bible.txt` — все книги данной Библии подряд.
- `ot_bible.txt` — только Ветхий Завет, `nt_bible.txt` — только Новый Завет.
- `contents.txt` — оглавление: порядковый номер, Завет, название книги и число глав.
  Например, `01 | OT | Mwamulizo | 50` означает 50 глав в первой книге.

Папки книг названы по схеме `номер_OT_название` или `номер_NT_название`.
Нумерация общая: 01–39 — Ветхий Завет, 40–66 — Новый Завет.

Названия книг взяты с самого сайта и оставлены на языке перевода.
Тексты сохранены в UTF-8. Сохранены номера стихов, заголовки, абзацы и порядок
чтения на сайте. Меню, кнопки, реклама и всплывающие сноски в TXT не включены;
пробелы и пустые строки приведены к удобному для чтения виду.
Если перевод объединяет стихи или меняет их порядок, это сохранено как на сайте.

## Как получены тексты

1. Для каждой книги открыты страницы всех её глав на Bible.com.
2. HTML-страницы сохранены локально.
3. Из каждой страницы извлечена область с текстом главы.
4. Главы разложены по книгам и объединены в файлы книг, Заветов и всей Библии.

Исходные страницы находятся в `data/bible/raw/review_sources/`: 2378 файлов
`.html` или `.html.gz` (сжатый HTML). Имя, например `3039_GEN_1.html.gz`,
обозначает версию 3039, книгу Бытие (`GEN`) и главу 1. Соседние
`.request.json` содержат сведения о загрузке: URL, время, HTTP-статус,
размер и контрольную сумму  — для всех 2377 страниц.
HTML нужен для повторного экспорта без сети; JSON хранит историю загрузки.
[manifest.json](manifest.json) содержит адрес Bible.com для каждой главы,
путь к исходной странице и соответствующему TXT-файлу, SHA-256 TXT,
а также состав книг, их принадлежность к Заветам и число глав.

## Как повторить

Для запуска с нуля из корня проекта:

```powershell
python export_bible_com_texts.py --download
```

Скрипт найдёт ссылки на главы в оглавлениях двух изданий, скачает недостающие
HTML-страницы и соберёт TXT. Страницы сохраняются в `data/bible/raw/review_sources/`.
Параметр `--output` позволяет собрать результат в отдельную папку.

Для повторной сборки из сохранённых страниц без сети:

```powershell
python export_bible_com_texts.py
```

При загрузке с нуля результат зависит от того, какие тексты и разметку отдаёт
сайт на момент запуска.
